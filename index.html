THE PRODUCT QUESTION

Should we expand a new guided setup flow from 10% to 50% of new accounts?

The scenario and all values below are illustrative. No live customer data or production launch is represented.

10% pilot→Evidence review→Decision receipt
01 / Problem

Setup stalls early

New accounts leave before connecting their first data source. The team proposes a guided setup flow to make that first task easier.

02 / Tradeoff

Speed can create friction

More guidance may improve activation while increasing support contacts or slowing the page. Expansion needs both benefit and acceptable cost.

03 / Decision

Use explicit gates

Compare the pilot with the current flow, check instrumentation and rollback readiness, then record the next action.
